==================================================
   小红书配图便捷生成工具（免安装版）使用说明
==================================================

【这是什么】

一个双击就能用的小工具。不需要安装 Python、不需要联网、
不需要任何配置，只要电脑上有浏览器就能用。
所有图片都在你自己电脑上处理，不会上传到任何地方。

【怎么启动】

  双击「配图工具.html」，会自动用浏览器打开工具页面。
  就这么简单。

【怎么用】

  1. 把图片拖进页面左上角，或点击选择图片
     （支持 JPG / PNG / GIF / WebP / BMP）；
  2. 在模板库里点模板，添加到配图方案（可重复添加，
     组成多页）；
  3. 点「生成预览」；
  4. 在预览里可以逐页换模板、点「图位」换图片；
  5. 满意后点底部：
     · 「打包 ZIP 下载」：得到一个压缩包，每个方案一个文件夹；
     · 「保存到文件夹」：直接选一个文件夹保存图片
       （推荐用 Chrome 或 Edge 浏览器；火狐/Safari 会
        自动改为 ZIP 下载，效果一样）。

【关于关闭页面】

  这个版本不需要保持任何程序运行，关掉浏览器页面就是
  关闭了工具，下次再双击「配图工具.html」即可。
  注意：关闭页面前请先导出成品，因为刷新/关闭页面后
  未导出的图片和预览会清空（自己保存的模板不会丢失）。

【想换电脑用 / 发给朋友】

  把整个文件夹（或「配图工具.html」这一个文件）复制
  过去就行，双击即可使用。

【推荐浏览器】

  Chrome / Edge 88 或以上版本体验最佳
  （Windows 10/11 自带的 Edge 直接就能用）；
  Firefox 89+、Safari 15+ 也可使用。
